# Solo Launcher - Monarch System v4.0

A personalized, gamified focus launcher and operating environment built with Kotlin and Android SDK.

## Features
- **Focus Gates**: 50-minute deep work blocks (Pomodoro-style).
- **EDITH Protocol**: Restricts S-Rank entertainment hazards.
- **Luna AI Assistant**: Integrated checklist and speech input.
- **Cognitive Attributes**: Dynamic leveling, XP, Gold, and Stat scaling.
- **Sci-Fi HUD**: Minimalist, high-contrast, dark mode interface.
